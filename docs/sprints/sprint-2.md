# Sprint 02 - Requisitos, arquitetura e documentação

**Período:** 24/08/2026 - 06/09/2026

**Objetivo:** Transformar as ideias e propostas iniciais em requisitos mais elaborados e estabelecer a organização técnica do projeto.

## Principais acontecimentos:
- Discussão sobre:
  - Product Canvas;
  - Protótipo;
  - Backlog do Produto.
- Discussão sobre permissões para criação de eventos.
- Avaliação de duas abordagens:
  - Restringir postagem a contas específicas;
  - Utilizar IA para analisar se uma postagem é válida no contexto da UnB.
- Discussão sobre uso de RAG para auxiliar a validação das postagens.
- Discussão sobre login e contas institucionais.
- Limpeza e organização do repositório.
- Uso de branches e Pull Requests.
- Definição de fluxo de desenvolvimento:
  - `branch` → `dev` → `testes` → `main`.
- Implementação do protótipo do front-end no GitHub.
- Compressão dos vídeos do site, reduzindo um arquivo de aproximadamente 15 MB para 1,6 MB.
- Definição de tarefas relacionadas a:
  - Specs;
  - Skills;
  - Figma;
  - Requisitos funcionais e não funcionais.

## Entregas/resultados da Sprint:
- Repositório organizado (placeholders e `.gitignore` configurados).
- Fluxo de branches definido.
- Front-end da primeira página sendo implementado.
- Documentação de requisitos.
- Estrutura inicial para gerenciamento do projeto.

# Sprint 03 - Validação e preparações iniciais para a Release 1 (28/09)

**Período:** 07/09/2026 - 20/09/2026

**Objetivo:** Produzir os demais documentos exigidos pela disciplina, validar e implementar feedbacks obtidos durante a aula e início da implementação da autenticação para a Release 1.

## Principais acontecimentos:
- Organização das tarefas restantes:
  - Arquivo de Skills e refinamento das specs;
  - Requisitos funcionais e não funcionais;
- Distribuição das tarefas entre as equipes:
  - **Front:** Figma + Issues;
  - **Back:** Skills/Specs + requisitos;
  - **Dados:** Product Canvas / Documento de Visão.
- Definição da necessidade de:
  - Logs das reuniões;
  - Commits semanais;
  - Diário de bordo individual.
- Definição da Release 1 para 28/09/2026.
- Implementação do GitHub Pages.
- Apresentação do grupo em aula e feedback:
  - Corrigir a estrutura do Story Map;
  - Revisar requisitos funcionais e não funcionais;
  - Priorizar melhor o que é realmente necessário;
  - Pesquisar projetos existentes;
  - Realizar benchmark.
- Discussão sobre scraping do SIGAA e seus riscos de manutenção.
- Evolução da autenticação/login.
- Back-end e banco de dados passam a ser cobrados como partes necessárias para a integração.

## Entregas/resultados da Sprint:
- GitHub Pages publicado.
- Story Map desenvolvido.
- Documento de Visão desenvolvido.
- Figma iniciado/preenchido.
- Autenticação em desenvolvimento.
- Alteração do front-end para permitir entrada como visitante (feedback).
- Apresentação da nova interface do front-end e do placeholder (roteamento) para a segunda página da aplicação (19/09).
- Discussão técnica sobre scraping e integração com dados acadêmicos.
